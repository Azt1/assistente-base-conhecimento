# Entregas da Loja Aurora

A Loja Aurora é uma empresa fictícia usada nesta demonstração.
O prazo de entrega dos pedidos é de 5 a 8 dias úteis após a confirmação do pagamento.
O código de rastreamento é enviado por e-mail quando o pedido é despachado.
Esta base não contém valores de frete nem informações sobre pedidos individuais.
